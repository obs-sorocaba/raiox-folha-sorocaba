# Raio-X do Quadro de Pessoal da Prefeitura de Sorocaba

Painel público, histórico e comparável da folha de pagamento da Prefeitura de Sorocaba.

Mantido pelo **Observatório Social do Brasil — Sorocaba**.

## Estrutura

- `index.html` — visão geral da folha
- `secretarias.html` — análise por secretaria
- `quadro.html` — escolaridade, tempo de casa e composição
- `genero.html` — análise de gênero
- `sobre.html` — metodologia, base legal e roadmap
- `dados/` — arquivos CSV e JSON consumidos pelo site
- `assets/` — CSS e JavaScript

## Fonte dos dados

- Portal da Transparência de Sorocaba: https://transparencia.sorocaba.sp.gov.br
- Base de gênero por nome: IBGE/Censo 2010, tratada por Álvaro Justen/Brasil.IO (CC-BY-SA)
